# 应用 UI 统一 · 2026-10-16

## 方向

用户指定以现有首页为主题基准。全局使用浅蓝白背景、墨蓝正文、青绿操作色；任务内容仍在对话中就地显示，各业务保留图表、商品、日历等必要布局。

## 本次落地

- `src/index.css` 与 `src/components/app-theme.css` 提供共享主题、详情页层级、导航、弹窗及控件规则。
- `TaskCardHeader` 统一账单、转账、订阅、跨场景、AA、生日与点餐任务头。阶段标签与来源说明分离。
- 正文以 14px 为基准，辅助文字至少 12px，主要操作目标至少 44px；卡片圆角 14px，控件圆角 10px。
- 财富对话默认收起，展开保留草稿和会话；产品提前进入首屏。基金详情页不重复叠加外边距。
- 转账弹层将表单滚动与底部操作区分开；AA 结算、生日方案核对不再藏在折叠内容里。
- 日历、卡片、订阅和账单详情页跟随共享主题；订阅、账单的导航归属与入口一致。
- 对话通用按钮样式排除共享 Button 和 Switch，防止覆盖主操作色与开关尺寸。
- 首页底部收紧：原生导航 64px，输入区实测约 81px，共比原来减少 33px；输入及语音按钮仍为 44px。安全区由导航承接，输入区定位和聊天滚动预留使用同一底部尺寸变量；经典模式维持原布局。
- 首页顶部收紧：缩减两行上下留白，头像 40px、名称 20px，导航仍保留 44px 点击范围；390px 手机宽度实测顶部高度 113px。
