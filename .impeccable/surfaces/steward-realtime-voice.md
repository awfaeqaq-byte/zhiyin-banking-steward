# 管家实时语音 · 局部表面记录

## Scope and mode

Operate。本次仅延伸 AI 原生首页的固定输入区：一个麦克风入口打开就地语音面板，连续聆听、打断与简短播报共享当前管家及既有后台事项。根 `PRODUCT.md`、`DESIGN.md` 与 `.impeccable/design.json` 继续拥有产品和全局视觉约定；本记录中的尺寸、配色例外及行为只适用于语音表面，不建立新视觉系统。

经典款／AI 原生仍在设置的“使用模式”单选组切换。经典款语音入口解释如何进入 AI 原生首页；没有新增首页模式切换器。语音只在 AI 原生首页且没有金融核对面板或通用弹层时可用。

## Composition and inherited identity

麦克风与原文字输入框并列，资金确认提示横跨二者下方。收起时保留首页的安静留白。展开面板在麦克风上方、右侧对齐，不遮罩整页、不把首页改成独立通话屏；原方案、依据与授权入口继续留在首页。

沿用青绿操作、墨蓝正文、灰蓝辅助字、白色面与细边框，使用现有 CSS 变量，不添加全局 token。复用当前宁宁／阿衡头像，无新增人物或栅格设计素材。面板内距（16px）、圆角（16px），宽度为 `min(350px, calc(100vw - 40px))`，高度上限为 `min(480px, calc(100dvh - 160px))`，长内容在面板内滚动。头像（38px）；标题（16px）、字幕（14px）、告知与按钮（13px）、状态（12px）、核对提示（11px）。这些是局部尺度，不作为新正文默认值。

开始操作为青绿底白字；静音为浅青绿次级操作；结束操作用浅暖面、谨慎红文字及“结束对话”表达含义。没有新增面板投影。字幕以“你说”和当前管家名字标注说话者，长文本可换行并在各自区域内滚动（最高104px）。

现有 `home-ui-preview.css` 对输入区内所有按钮指定圆形与统一底色。语音 CSS 以输入区、语音容器和具体按钮共同限定选择器，明确恢复入口、关闭、开始、结束及禁用样式；兼容修正仅覆盖语音按钮，不改文字发送按钮或首页预览的全局规则。

## Start, states and recovery

点麦克风只展开面板，不申请麦克风或自动连接。开始前显示音频、对话与必要业务结果将发送至阿里云百炼处理、离开即停收音及本项目不保存原始录音的告知，再由用户点击“开始语音对话”。服务就绪检查先于麦克风申请；未配置凭证、非安全上下文或不支持的浏览器显示具体恢复提示。

| 状态 | 可见行为 |
| --- | --- |
| 尚未开始／已结束 | 告知、开始按钮与核对提示；可继续打字。 |
| 连接中 | “正在连接…”及旋转图标；麦克风等待会话配置确认后才启用。 |
| 聆听 | “正在聆听”，显示本轮识别字幕；可静音或结束。 |
| 处理事项 | “{管家}正在处理，暂时暂停收音”；暂关音轨，等待既有任务回执。 |
| 播报 | “{管家}正在回应”，显示管家字幕；新讲话事件取消旧回复并停止旧音频。 |
| 静音 | “麦克风已静音”，按钮改为“恢复收音”；已经允许的管家播报可继续。 |
| 错误／连接中断 | 释放媒体资源，以文字错误说明恢复路径，不能显示仍在通话。 |
| 浏览器阻止声音 | 状态说明配“播放声音”，用户手动恢复播放。 |

活动语音期间禁用文字输入与发送，避免同时交代；文字发送、后台忙碌、视图保存或微信分享处理中不能新开语音。关闭按钮、再次点麦克风、Escape、手机返回都会停收音并收起面板，焦点回到麦克风入口。“结束对话”只结束连接，面板保留，可重新开始或继续打字。结束保留上次识别文字供核对，管家字幕只在活动语音期间显示。

离开首页、切换使用模式、打开金融核对或通用弹层会停止并收起语音。页面隐藏、知银失去沙箱手机前台、切换管家、上下文重置及组件卸载也会释放连接、音轨和播放器。手机后台消息仅接受同源父窗口。单次会话最多5分钟，超时写明已结束收音。回到首页或前台不会自动重启；需要用户重新点击开始。

## Shared task and authorization boundary

最终识别原文通过现有 `arrange` 消息流程进入同一个后台事项，按语音轮次标识去重；不使用实时模型改写的工具金额代替用户原话。回执从原事项与会话记录取得，语音模型仅简短转述。无有效原文、未知工具、失效轮次或退出后的迟到事件不能新增任务。

语音结束会中止等待，不代表撤回已经提交的事项；首页保留实际进度。失败或超时提示先核对首页，不能宣称执行成功或鼓励重复提交。口头“好”“确认”不替代原页面的本人授权；转账、付款、存入、支取、取消等仍走既有核对与确认界面。资金操作提示在输入区和语音面板持续可见，沙箱数据标识沿用首页。

## Accessibility and motion

麦克风具有当前管家名称与 `aria-expanded`；面板是名为“语音对话”的非模态 `region`，不宣称有对话框焦点陷阱。关闭、静音／恢复有明确可访问名称；头像为装饰。状态与通知使用 `role="status"`，错误使用 `role="alert"`。字幕有可读说话者标签，但未另外承诺实时字幕逐字播报。入口、关闭和通话控制至少44px，键盘焦点为青绿轮廓（2px、偏移3px）；状态不依赖颜色。

面板以180ms、`cubic-bezier(.16,1,.3,1)` 的4px轻移及裁切进入；`prefers-reduced-motion: reduce` 关闭面板进入动画，加载旋转沿用现有全局规则。没有新增循环装饰动画。

## Local operator configuration

沙箱控制台“模型配置”下以原生 `details`／`summary` 分开“文本模型”和“实时语音”；分组标题最小52px，字段纵向排列，手机继续沿用控制台滚动面板。实时语音显示当前配置状态与模型，地域、业务空间、密码型密钥字段可编辑，管家音色收在详情展开中。输入与选择控件至少44px，保留标签与可见焦点。

仅展开活动组时读取配置；加载或保存中禁用字段，成功使用状态反馈，失败使用 alert。密钥不回显，关闭或保存后清空输入；留空保留现有密钥，更换地域或业务空间需重新输入。保存说明下一次开始生效，不发起通话。控制台是本机操作工具，不向普通首页用户暴露配置表单。提供方、部署、密钥存储和 API 细节以根 `README.md` 为准，不在此复制设置手册。
