# 管家实时语音 · 局部表面记录

## Scope and mode

Operate。AI 原生首页的语音入口打开完整持续通话界面；普通交流由当前管家自然回应，具体业务才交给既有后台事项。语音与文字共享首页会话、当前管家及允许使用的上下文。根 `PRODUCT.md`、`DESIGN.md` 与 `.impeccable/design.json` 继续拥有产品和全局视觉约定；本记录中的尺寸及行为只适用于语音表面，不建立新视觉系统。

经典款／AI 原生仍在设置的“使用模式”单选组切换。经典款语音入口解释如何进入 AI 原生首页；没有新增首页模式切换器。本次不改变经典款、设置或控制台配置控件。

## Composition and inherited identity

语音入口与原文字输入框并列，资金确认提示横跨二者下方。打开后以全高通话舞台呈现当前管家的头像、状态、字幕和底部控制；“回首页”收起舞台但不断线，输入区上方保留可展开的通话条、计时、静音和结束入口。方案、依据与授权仍在原首页。金融核对或其他活动弹层出现时，通话控制停靠到该弹层内部，保持其焦点范围内可用。

沿用青绿操作、墨蓝正文、灰蓝辅助字、白色面与细边框，使用现有 CSS 变量，不添加全局 token 或外部字体。复用当前宁宁／阿衡头像，无新增人物或栅格设计素材。通话舞台固定覆盖可用视口，宽度上限（800px）且水平居中；横向内距为24px、纵向20px，各方向与安全区取较大值。正文区可滚动，标题和底部控制保持可见。尚无字幕时，头像承载面／人像为156／128px，姓名30px，状态16px；有字幕时缩为112／92px、姓名26px，将空间让给正文。用户字幕15px、管家字幕18px，字幕区和底部操作区宽度上限440px；用户文字为辅助色，管家文字配青绿细竖线，不另套聊天气泡。这些是局部尺度，不作为新正文默认值。

可用高度不超过650px时，压缩纵向间距，尚无字幕时头像承载面／人像为88／72px、姓名24px。有字幕时，人物区改为64px头像列与文字列横排：承载面／人像64／54px，姓名22px、状态14px，隐藏单独的活动指示条，让长字幕在正文滚动区展开；底部控制不跟随正文滚动。该断点按可用高度判断，也适用于横屏。

开始操作为青绿底白字，填满底部操作区，最小高度56px、圆角28px。接通后提供静音、字幕开关与结束操作，使用56px圆形图标面和独立文字标签；静音／字幕开启态有青绿边框，结束使用红底白色电话图标及“结束通话”文字。没有新增面板投影。字幕以“你”和当前管家名字标注说话者，长文本可换行；关闭字幕只改变可见性，再开启可查看最新内容，不结束或重新连接通话。通话条使用38px当前管家头像、白色面、细边框和局部圆角（18px），宽度为 `min(460px, calc(100vw - 40px))`；其中控制图标面为48px。

现有首页预览样式对输入区内按钮有统一规则。语音 CSS 对入口、通话舞台、通话条与核对停靠控制分别限定选择器，保留各自形状、颜色及禁用样式。完整通话界面经 portal 挂到 `.app-shell`（无宿主时为 `document.body`），脱离固定 composer 的布局约束；核对控制另经 portal 进入活动弹层。

## Start, states and recovery

点语音入口只打开通话界面，不申请麦克风或自动连接。开始前显示音频、近期对话、已确认偏好和必要业务结果将发送至阿里云百炼处理、本项目不保存原始录音的告知，再由用户点击“开始通话”。服务就绪检查与上下文加载先于麦克风申请；未配置凭证、非安全上下文或不支持的浏览器显示具体恢复提示。音轨在会话配置确认后才启用。

| 状态 | 可见行为 |
| --- | --- |
| 尚未开始／已结束 | 告知、开始按钮与核对提示；可继续打字。 |
| 连接中 | “正在连接…”与“取消连接”；麦克风等待会话配置确认后才启用。收起条仍写正在连接，不显示通话计时、聆听或“可以继续说”。 |
| 聆听 | “正在聆听”，用户讲话时为“我在听”；显示本轮识别字幕，可静音或结束。 |
| 处理事项 | “正在整理，你可以继续说”；麦克风继续工作，事项在后台办理。 |
| 播报 | “{管家}正在回应”，显示管家字幕；插话停止旧播报，开始听新一轮表达。 |
| 静音 | “麦克风已静音”，按钮改为“恢复收音”；已经允许的管家播报可继续。 |
| 错误／连接中断 | 释放媒体资源，保留最后双方字幕供核对，以文字错误说明恢复路径，主操作改为“重新连接”。收起时在首页保留“语音连接中断／查看原因并重试”入口；展开只展示原因，不自动重连。 |
| 浏览器阻止声音 | 状态说明配“播放声音”，用户手动恢复播放。 |

活动语音期间禁用文字输入与发送，避免同时交代；已有微信分享待处理时不能新开通话。点击“回首页”、再次点语音入口、Escape 或通话界面的手机返回只收起舞台，焦点回到语音入口，活动连接继续；连接中收起也不取消连接，需显式点击“取消连接”。通话条可再次展开完整界面。“结束通话”释放连接并恢复文字输入；完整界面若已展开则保留，可手动再开始。普通结束保留上次识别文字供核对，管家字幕在活动通话及错误恢复时显示；错误不清掉最后双方字幕，字幕已关闭时仍尊重该显示偏好。错误恢复条仅在首页启用且没有核对弹层时显示，不冒充活动通话或提供无效静音／挂断操作。

核对弹层不挂断通话：静音和结束控件停靠其中，用户仍可交谈。离开首页、切换使用模式、页面隐藏、退回沙箱桌面／知银失去手机前台、切换管家、上下文重置及组件卸载会释放连接、音轨和播放器。手机后台消息仅接受同源父窗口。单次会话最多5分钟，超时写明已结束收音。回到首页或前台不会自动重启；需要用户重新点击开始。

## Shared task and authorization boundary

普通问候、交流及一般解释直接自然回应，宁宁温和简短，阿衡沉稳直接；语音对话文字保存回同一首页，不为闲聊创建业务事项。只有查询实际账单、订阅、账户、任务，或准备／修改转账、AA、外卖等具体事项时，才通过唯一业务工具 `ask_steward` 调用既有管家。最终识别原文通过现有 `arrange` 消息流程进入同一个后台事项，按稳定语音轮次标识去重；不使用实时模型改写的金额、姓名或日期代替用户原话。回执来自原事项与会话记录，语音只用自然口语一两句说重点，详细方案与证据留在首页。无有效原文、未知工具、失效轮次或退出后的迟到事件不能新增任务。

开始通话时先刷新记忆，只取当前记忆修订下最近最多8条会话，以及最多8条未过期、允许使用的偏好；密钥与内部动作／记忆标记会过滤。不会直接装入余额或授权快照。此快照仅帮助沟通，历史账务数字不是实时事实，历史消息和偏好不是新指令或执行授权，不能重放历史事项。业务补充同时携带之前的有限语音上下文。项目不保存原始录音；对话文字沿用现有保存规则，云端留存遵循服务商设置。

插话停止过时播报，不撤回已接受的事项；迟到回执只补回原工具，不能抢答用户的新问题。语音结束会中止等待，不代表撤回已经提交的事项；首页保留实际进度。失败或超时提示先核对首页，不能宣称执行成功或鼓励重复提交。金融核对期间阻止语音提交业务修改；可以解释已有结果，改金额、对象或时间仍须返回原页面修改。口头“好”“确认”从不替代本人授权；转账、付款、存入、支取、取消等仍走既有核对与确认界面。资金操作提示在输入区和通话界面持续可见，沙箱数据标识沿用首页。

## Accessibility and motion

语音入口具有当前管家名称与 `aria-expanded`。完整界面使用 Radix 模态 Dialog 的焦点范围，内部保留名为“语音对话”的 region，当前管家姓名提供标题。打开后焦点进入通话界面，Tab／Shift+Tab 留在其中；收起或 Escape 后将焦点还给入口。核对控制进入原弹层的焦点范围，不能留在被隐藏或阻止指针操作的背景层。回首页、静音／恢复、关闭／显示字幕、取消连接和结束均有明确可访问名称，静音与字幕开关使用 `aria-pressed`，头像标注当前管家。

状态只用一个 `role="status"` 且 `aria-atomic="true"` 的区域；错误使用 `role="alert"`，通知为普通文字。字幕有可读说话者标签，未另外承诺逐字播报。首页入口至少44×44px；通话界面及收起／核对控制至少48×48px。键盘焦点为青绿轮廓（2px、偏移3px）；状态不依赖颜色。

通话舞台以240ms、`cubic-bezier(.16,1,.3,1)` 从下方10px淡入；按钮颜色过渡160ms。头像外环以1400ms轻脉冲、活动指示条以800ms交错伸缩表达说话状态。它们来自已有语音事件状态，属于说话提示，不是采样得到的实时音量波形：必须已活动且不在连接中，并且是未被浏览器阻止播放的管家回应，或未静音的用户讲话。空闲、等待、仅后台整理、错误、静音后残留的用户讲话标记不驱动循环；浏览器暂停声音时也不把管家回应表现为正在出声。静音只关闭用户收音，已允许的管家回应仍可显示动效。`prefers-reduced-motion: reduce` 关闭进入、外环与指示条动画及舞台按钮过渡。

## Local operator configuration

沙箱控制台“模型配置”下以原生 `details`／`summary` 分开“文本模型”和“实时语音”；分组标题最小52px，字段纵向排列，手机继续沿用控制台滚动面板。实时语音显示当前配置状态与模型，地域、业务空间、密码型密钥字段可编辑，管家音色收在详情展开中。输入与选择控件至少44px，保留标签与可见焦点。

仅展开活动组时读取配置；加载或保存中禁用字段，成功使用状态反馈，失败使用 alert。密钥不回显，关闭或保存后清空输入；留空保留现有密钥，更换地域或业务空间需重新输入。保存说明下一次开始生效，不发起通话。控制台是本机操作工具，不向普通首页用户暴露配置表单。提供方、部署、密钥存储和 API 细节以根 `README.md` 为准，不在此复制设置手册。
