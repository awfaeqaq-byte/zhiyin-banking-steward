# 资产总览与资金安排 · 2026-10-21

用户认为资产和财富页面过于朴素，希望像卡包一样有明确形态、可操作的业务组件。沿用首页浅蓝画布、青绿与墨蓝，借用卡包的深青和鼠尾草材质；不改首页、卡管理、外部沙箱或全局主题。

资产首屏是深青总览与真实资产分布环。总额只计算主账户 assetSummary.total 加其他银行卡现金，包含主卡现金、理财本金和定存本金；不包含微信支付宝余额，不补造收益或历史曲线。常用卡可用与已安排资金使用后端 availableCash/reservedCash，与全部银行卡合计明确区分。

资产分布提供四类选择（其他银行卡只在确实存在时出现）。选择即时联动环形占比、说明和明细入口；现金跳主卡、其他卡跳实际副卡、理财跳持仓、定存跳办理页。零资产不制造有色份额，未读取不展示零余额。隐藏金额同时遮住总额、占比、分类、已安排金额和时间线金额。

管家入口使用当前选定管家头像与名字，把当前资产类型带入首页草稿，用户确认表达后再发送。近期资金安排合并带 cardId 的 pending 预约、未支取定存和已识别即将续费，按日期展示最多三项。金额全部保持分单位；关闭提醒只影响提醒，不把待扣费事实从资金安排删除。到期定存标注手动支取；过期未完成项显示待核对，不冒充到账或扣费成功。相关项目打开原卡转账记录、定存或对应平台订阅；保留全日程与资金安排入口。

手机单列，760px 起分为资产与安排两列；金额采用等宽数字，分类与操作可键盘访问。图形和选择反馈仅做短过渡，减少动态效果时关闭。加载、读取失败与部分来源失败都有明确状态，不伪装空态。

交付验证覆盖真实总额与副卡计入、类型联动和导航、金额隐藏、无数据/错误状态、时间线排序/金额/多卡路由、关闭提醒仍保留续费安排。实际预览：`.impeccable/review/assets-wealth-20261021/phone-assets.png`。
