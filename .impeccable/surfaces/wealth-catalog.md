# 财富目录与基金筛选 · 局部表面记录

## Scope and direction

2026-10-15 用户要求扩大财富页产品展示，在财富页以一处小对话表达投入金额与持有期，精简反复出现的演示说明，将境外渠道测试移到沙箱控制台，并使选基页与知银身份、宁宁的产品推荐连通。本记录约束财富、财富小对话和基金筛选，不替换根设计系统或首页对话约定；境外渠道测试由沙箱控制台负责。

模式为 **Operate**。用户成功路径是“说出投入安排或关注方向 → 查看同一目录的候选和资料 → 继续问管家 → 对允许办理的账户产品单独核对与授权”。财富页负责计划、风险与账户操作，基金筛选负责搜索、比较资料和收藏；选基不再持有独立的假购买账本。

用户已明确要求财富页保留紧凑对话，因此该对话作为本业务页的辅助入口。它不会替换首页管家，不要求用户为不同产品建立任务窗口。

## Shared inventory and page relationship

`src/lib/wealth-catalog.ts` 是页面与模型共同使用的目录，保留稳定产品 ID，共 14 项：

- 3 项 `source: account` 账户产品来自现有 `wealthProducts`，包含风险等级、起购金额、递增金额、最短持有期、费率和赎回规则；办理能力仍由原账户 API 决定。
- 11 项 `source: fund` 基金资料来自现有选基数据，包含类型、关注方向和历史区间数值；风险等级未知、`purchasable: false`，不自动加入可交易库存。

财富页在小对话和风险状态后呈现账户产品，再呈现可按类型切换的基金目录。基金标题打开选基详情，“问宁宁”把该产品名称带入小对话草稿。顶部“基金筛选”打开完整列表。选基详情的“请宁宁分析”使用相同 ID 返回财富对话，并填入可修改的提问，不自动发送、不发起申购。

选基列表提供全部 11 项、名称/类型/方向搜索、实际基金类型筛选、近一周涨跌筛选，以及近一周/近三个月/近一年数值的升降序。它不再沿用缺少依据的人气、三年表现等榜单标签，也不展示虚构基金代码。自选仍保存在浏览器 `zhiyin-fund-watchlist`；旧 `zhiyin-fund-demo-orders` 不读、不写、不删除。

## Conversation and decision boundaries

App 内的 `WealthConversationProvider` 维护本次打开期间的计划、消息、草稿和请求状态。离开财富页进入选基再返回时，这些状态继续保留；这不是刷新页面后的持久化保证。聊天区域仅展示最近若干条消息并内部滚动，输入入口保持在小对话底部。

投入金额和持有期从用户明确表达提取，界面展示当前已知计划，不再把数字输入与月份滑块作为默认入口。模型不能用推荐值补齐资金计划。缺少信息时追问一两项，已有信息继续沿用；失败保留对话并提供重试，发送后清空已发送草稿。

风险评估缺失或失效时，可以浏览基金资料、讨论需求，但不输出个性化产品候选。有效评估下，账户产品候选经过风险、金额、期限和递增条件过滤。基金资料只能作为待核验的研究候选，明确提示风险、费用与交易状态尚未核验。模型目录不输入历史涨幅来推断适当性；模型候选 ID 必须存在于共享目录，响应最多保留 3 项。

推荐消息关联当时的计划与风险评估时间。计划变化或重新测评后，旧候选不继续作为当前可执行推荐展示。申购仍需已知金额与持有期、有效评估、账户读取成功、余额及费用核对，并通过独立确认面板授权；聊天与点击基金资料不会完成资金操作。账户产品在详情中说明交易记入本地账本，不把移除重复演示文案变成真实银行接入声明。

## Composition and visual language

沿用 `docs/home-ui-preview/DESIGN.md` 的浅蓝画布、白色内容面、墨蓝正文和青绿操作色。选基页主要颜色为 `#f1fafc`、`#ffffff`、`#133346`、`#506d7c`、`#007d7c` 与 `#d5ebee`；财富页继续使用既有相邻青绿/蓝灰色，不引入原选基页的紫蓝搜索栏、粉红横幅和彩色快捷大厅。

继续使用系统中文无衬线字体，产品名允许完整换行，金额与区间表现采用等宽数字。列表以细分隔线组织产品，不为每项重复套卡片。基金详情就地替换列表，不额外弹出购买模态框；返回后保留筛选条件并恢复到所选产品的键盘焦点。

手机选基布局为单列。类型与涨跌两个筛选并排，排序单独成行，结果数量与资料日期允许换行；641px 起将产品身份与指标横向排布。选基搜索、筛选、返回、收藏、详情入口至少 44px，主要详情行动至少 46px，具有可见焦点。财富小对话的消息区域有高度上限和滚动条；发送、示例、重试、资料分类控件已统一至少 44px 命中高度。

## Data provenance and copy

财富基金目录与选基列表保留一处简洁的资料日期/非实时说明。详情进一步说明数据来自既有选基截图录入、尚未经过官方核验，以及风险等级、费用和赎回规则待核验。历史数值不是实时报价或收益承诺。

账户产品保留起购门槛、风险、费用、持有期、资金来源和授权等必要信息；重复的“演示产品”“仅供学习”和假订单成功反馈已从这条选择路径移除。资料来源和办理边界放在决定需要的位置，不反复占据每行产品或每条回复。

## 2026-10-21 产品组件升级

延续既有主题并借用卡包的深青、鼠尾草和墨蓝材质，顶部只保留标题、基金筛选、紧凑余额和导航。有效风险评估下，先展示按真实最低持有期分组的账户产品架；0、6、12 个月期限条对应真实规则，风险、起购和费率明确。可横向浏览，每张产品有独立详情与管家解读入口，解读只带入该产品草稿，不自动发送或执行申购。计划与风险条件仍决定候选，不为填满组件扩展可售产品。

宁宁对话跟在产品后，风险状态压紧。未测评时允许先浏览基金资料，再从现有入口完成测评。基金目录默认提供三个不同类别的浏览入口，首项主题面板与紧凑条目形成层次；默认顺序不表示推荐或排名。可展开全部11项，或按实际类别筛选；资料、自选、详情和管家分析仍用同一产品ID。历史区间数值与资料日期保留，不绘制虚构走势。

核心验证包含期限筛选、计划变化、全部模式解读第二张卡、目录展开与分类，以及原有风险/计划/申购确认/持仓回归。实际预览：`.impeccable/review/assets-wealth-20261021/phone-wealth.png`。
