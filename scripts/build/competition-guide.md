# 知银比赛提交版

本包包含知银完整前后端源码、测试、必要手机沙箱、最新编译产物和展示素材。首次联网安装依赖，之后即可在本机启动。宁宁的模型对话和实时语音需要网络及自行配置的服务凭证。

## 1. 首次启动

安装 Node.js 22.13 或更高版本（包含 npm），将 ZIP 完整解压后，在 `zhiyin` 文件夹打开终端：

```sh
node scripts/build/competition-launch.mjs install
node scripts/build/competition-launch.mjs start
```

打开 **http://127.0.0.1:3000/**，在手机桌面点击「知银」。新浏览器会话默认进入当前的 AI 原生对话首页；已有模式选择会保留。请保持终端运行，结束时按 Ctrl+C。Windows 也可依次双击 `安装依赖.bat`、`启动.bat`；macOS 对应 `.command` 文件。若系统阻止双击，使用上面的终端命令。

首次安装严格按两个 `package-lock.json` 下载依赖；跳过与运行无关的 Puppeteer 浏览器下载。包内不含 Node.js、npm 安装缓存或本机 `node_modules`，可由各电脑安装适配自身系统的依赖。

源码和编译目录中内容完全一致的素材只压缩保存一份。上述安装/启动脚本会按 `shared-file-copies.json` 在本地还原缺少的副本并验证来源 SHA-256，不需要额外下载素材。请先运行安装脚本，再直接使用其他 npm 命令。

## 2. 模型与可选行情环境

- 文字对话：打开页面旁的「沙箱控制台 → 模型配置」，填写兼容服务地址、模型名称、API Key，再保存。没有模型凭证仍可查看界面、账户和沙箱应用，但不能验收完整自然语言任务办理。
- 连续语音：在同一控制台的实时语音设置中配置项目所用百炼服务，并允许浏览器麦克风权限。语音服务授权需单独验证；文本模型配置不会自动开通语音。
- 本包不携带开发者的 API 密钥、个人账单、历史聊天或已授权任务。首次打开使用代码内置样例，跨平台读取仍由用户授权。
- 实时行情及基金数据：如需体验，先安装 Python 3.10 或更高版本，再执行 `node scripts/build/competition-launch.mjs python`。之后用上述启动脚本运行，它会自动使用项目虚拟环境。实时行情仍依赖数据源联网可用性；未安装 Python 时不影响首页、沙箱、转账、账单样例、卡管理等基础体验。

## 3. 建议体验顺序

| 环节 | 操作与观察点 |
| --- | --- |
| 首页与资产 | 进入知银，切换管家、资产、财富、卡片和我的；观察统一样式、银行卡钱包和业务组件。 |
| 转账核对 | 配置模型后说「明天中午给妈妈转账 100 元」，核对联系人、时间及授权卡片；日程中查看任务。 |
| 跨平台账单 | 在知银连接设置中授权微信、支付宝，再要求分析账单；查看来源、去重和分析组件。 |
| AA 与微信衔接 | 选择微信群，记录聚餐消费、个人消费与分摊规则，查看 AA 账本及微信群收款衔接。 |
| 微信里的宁宁 | 打开沙箱微信的宁宁联系人，体验文字聊天；指定消息分享给知银后继续办理。 |
| 订阅和卡管理 | 授权订阅来源，查看续费安排；体验卡片限额、挂失、支付开关和核对流程。 |
| 长辈模式 | 在知银设置中切换长辈模式，观察字体、操作目标、对话与业务卡片适配。 |
| 我的小店 | 进入小店，查看扫码点餐、订单、菜品收入和资金安排；完整流程从新建订单开始。 |

资金和外部平台均在本地拟真沙箱中运行，不会连接真实支付账户。模型回复需以业务核对卡和沙箱回执为准。定时任务需要本机服务持续运行。首次打开本包与已有浏览器环境的历史状态不同，这是隔离的新体验环境。

## 4. 保留范围与体积控制

知银六大功能、长辈模式、小店、任务记忆和后台调度源码完整保留。沙箱保留微信、支付宝、外卖、地图、铁路、天气、会议、微信读书及系统应用。地图离线资源、默认壁纸、主题图标、时钟和天气小组件、输入法词库、头像和内置样例图片均随包提供。

精简项为与知银演示无直接关系的视频、资讯与音乐应用及其大数据集、强化学习环境、历史发布包和重复编译文件。默认主题资源目录同时按实际保留内容裁剪，不显示未打包主题。完整开发工程保持原样；本包的范围见 `submission-profile.json`。

## 5. 代码、测试与重建

```sh
npm test -- --maxWorkers=2 --minWorkers=1
npm run lint
npm run build
node scripts/build/competition-launch.mjs dev
```

`start` 使用已编译页面，`dev` 会重新同步知银并启动开发服务。源码改动后请重新构建。运行时数据在本机创建；不要把自己配置后的密钥和历史数据再次分发。`验收记录/` 提供本次提交包的实际验证结果与界面截图，`file-manifest.json` 列出打包文件和 SHA-256。

沙箱基于 MobileGym；原作者声明、源码与数据授权条款分别保留在 `mobilegym/NOTICE`、`mobilegym/LICENSE`、`mobilegym/LICENSE-DATA` 和 `mobilegym/DISCLAIMER.md`。
