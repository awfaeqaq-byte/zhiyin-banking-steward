# Overleaf 使用说明

本项目是对原始 Word 笔记的重新编排版，不是新增的项目实施方案。

## 文件

- `main.tex`：主文档；
- `source-assets/`：原始 Word 中的 16 张图片，按出现顺序编号；
- `README.md`：编译说明。

## 上传到 Overleaf

1. 上传交付的 ZIP 文件；
2. 将编译器设置为 `XeLaTeX`；
3. 将主文件设置为 `main.tex`；
4. 点击 `Recompile`。

## 标注规则

- `赛方原话`：原始笔记明确注明的公众号原话；
- `赛方公开图片`：赛方公众号公开配图；
- `赛方直播截图`：大赛直播第一场截图；
- `我的意见`：原始笔记中的个人批注，经语句整理但没有扩展观点；
- `参考资料`：原始笔记没有记录完整出处的课件或案例图，不作为赛方表述。

正式对外引用前，应补齐公众号文章和直播的链接、发布日期及访问日期。
