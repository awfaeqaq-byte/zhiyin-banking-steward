## 财富页和选基页的关系

财富页是日常入口：可用余额、小对话、账户产品、基金目录、持仓。选基页是同一目录的筛选工具，支持名称搜索、实际类型过滤、近周/季/年历史数值排序与自选。排序只表示这份静态资料内的顺序，不再标为全市场人气榜或三年排行榜。

点基金进入选基详情，点「请宁宁分析」携带产品 ID 返回财富页并准备问题，用户发送后才请求模型。旧选基页只写 localStorage 的假申购记录已移除；可执行的申购、赎回仍统一走财富账本。产品数据没有因此变为实时、已核验或真实可售。

## 推荐与比较流程

1. `WealthConversationProvider` 在 App 内维护同一段对话、草稿与计划，切换选基/财富页面仍保留；独立挂载财富组件时使用本地 Provider。页面默认没有金额和持有期，不再填入 30,000 元、12 个月。
2. `extractWealthPlan` 从明确的用户表达整理金额/期限，模型不能替用户补默认投入。缺项在小对话中继续追问；文本不会改变风险测评或授权交易。
3. `requestWealthConversation` 通过既有模型代理传入共享目录与当前测评；输出文本和受控候选 ID。未完成有效测评不提供产品目录。账户候选必须再经过 `suitableWealthProducts` 的风险、起购、期限、递增条件核验；基金资料候选仅标为待核验，不新增购买权限。
4. 小对话显示当前投入计划和候选理由，点击账户候选进入已有产品核对流程；点击资料候选进入同一基金详情。日期、资料范围和缺失信息集中在详情/来源说明，页面不再反复堆叠“演示、仅供学习”。
5. 产品详情按最新计划计算费用、检查余额；生成方案后仍需用户独立确认，服务端复查风险、资金及有效期并生成回执。对话本身不调用申购或赎回动作。
6. 首页宁宁的理财上下文同时接入共享的基金目录，已知产品 ID、风险信息和资料来源与财富页一致。市场接口仍仅提供背景，历史涨幅不作为适当性依据。

## 测试工具位置

境外渠道验证位于「沙箱控制台 → 财务测试」。卡片页保留境外交易开关；测试面板在明确确认 ¥1.00 后调用原银行 payment API，服务端仍执行卡控。结果不明时沿用同一交易 ID 核对，避免重复扣款；成功后通过校验 origin/source 的 `bank-updated` 桥通知知银刷新余额，不重新加载对话。

对费用与赎回条件逐项比较，是因为费用会减少可投资金额、不同基金的成本结构及退出条件会影响结果；历史表现无法保证未来收益。[Investor.gov 基金说明](https://www.investor.gov/introduction-investing/investing-basics/investment-products/mutual-funds-and-exchange-traded-funds-etfs/mutual-funds)、[费用影响说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/updated)。

## 借鉴 InBridge 的范围

[InBridge](https://github.com/xyzxyq/InBridge) 是 Apache-2.0 的 ChatGPT MCP App。它的核心经验是：模型提出结构化选择，受控组件处理输入验证和状态，用户明确提交后再把结构化结果交还模型。本项目采用同一原则，但没有复制其 MCP/ChatGPT 宿主桥接代码，也不依赖 OpenAI 的 Visualize 在本应用内运行。

目前白名单只有 `WEALTH_COMPARE`。模型可以输出 `[ZHIYIN_VIEW:WEALTH_COMPARE]`，解析器去掉标记并显示项目自有 React 组件。未知视图标记被丢弃，模型不能提供 HTML、脚本、产品价格或交易按钮定义。用户明确要求产品比较时，界面还会提供本地兜底显示，避免漏标记导致无法探索。以后可用版本化 JSON schema 增加预算规划器、债务策略比较等视图；schema 必须限制组件类型、字段来源、数值范围、跳转目标及执行权限。

## 验收场景

- 未测评：可浏览中性基金目录，但对话不提供推荐或比较；引导完成测评。
- 谨慎型：R2/R3 不出现在适当性候选；行情上涨不改变风险上限。
- 多产品：财富目录与选基详情使用同一 ID；对话更新计划后费用与候选同步，现金不足时禁止生成待确认方案。
- 市场接口缺失、过期或部分失败：保留可用数据并标日期，不给出伪实时结论。
- 用户选中产品后改变约束：按钮必须按最新条件禁用；最终仍由服务端复核。
- 模型返回未知视图或任意 HTML：解析器只认白名单标记，普通回复按安全文本渲染。

当前仍缺少获得授权的实时基金目录、可交易报价、完整费用和可售状态。AKShare 历史样本不能替代它们，因此没有上线真实产品推荐或自动申购；接入时必须逐项建立来源、许可、更新时间和失效处理。
