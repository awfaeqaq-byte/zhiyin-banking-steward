# 智能转账测试说明

入口：知银 → 资产 → 我的银行卡「管理」→ 智能转账与AA收款。AI原生模式也可直接向宁宁交代需求，点击回复中的核对按钮。

## 可测试的对话

- 给妈妈转100元，现在转。
- 给13800006621转100元。
- 给备注是母亲的联系人转100元。
- 后天上午10点给妈妈转200元。
- 聚餐花了100元，我和妈妈、爸爸三个人AA，包含我，帮我发起收款。

收款人是已登记的独立银行沙箱账户：妈妈、爸爸、张三、李四、王五。支持姓名、手机号及登记备注查询；“同事”会匹配多人，需要进一步选择。尚未实现任意通讯录联系人的自动银行开户，不能把手机号当成银行卡号。微信、支付宝钱包与这些银行沙箱账户分开。

## 执行规则

金额均以整数分持久化到原银行账本。准备方案不扣款，用户在核对页授权后才执行。即时转账回执、预约、AA请求和AA入账均在同一个文件锁及原子写入边界内更新，重复提交使用原请求ID，不重复记账。

预约是单次任务，不冻结资金。Node开发/预览服务器每秒检查一次；前端关闭后仍执行。服务关闭时不会执行，重启后处理到期任务。到期重新校验余额、单笔限额、挂失、夜间保护，失败记录原因且不扣款。失败不会自动重试，需重新核对授权。客户端显示设备当地时间，宁宁按北京时间理解自然语言。

AA总额按人数均分，尾差按参与顺序分配，包含自己时自己排第一。100元三人是33.34、33.33、33.33元，自己的部分不收款。发起后可在「记录」中查看待收状态；展开「测试对方付款」，选择参与人并确认，可模拟对方银行账户付款并真实增加用户的沙箱银行卡余额。对方测试账户初始资金为10,000元，独立持久化扣减；不会自动从真实账户或微信支付宝扣款，也尚未向微信联系人发送收款通知。

结束AA只关闭尚未付款份额，已收款不撤回。AA入账在银行卡流水和智能转账记录中均可查看。

## 验证

`npm test` 覆盖检索、预约授权/执行/撤销/失败、AA尾差/幂等/账本恢复及前端授权边界。

`npm run phone:sync` 更新手机内的知银前端。保持3000端口手机服务运行后，执行 `node scripts/smart-transfer-smoke.mjs`，使用临时账本完成390px手机界面的转账、AA发起和对方付款测试，用户的账户数据不变。
