# 知银长期记忆 v1

## 使用

个人中心 → 管理记忆 → 允许记住我的偏好。默认关闭，不自动迁移 `zhiyin-memory` 内的演示条目。可以手动添加、修改、删除、清空；启用时宁宁也可依据当前用户原话提出候选，必须点击“确认记住”才会写入。

关闭后保留已保存数据，但不提供给模型，也不接受新记忆。相关记忆发送至用户已配置的模型服务，模型候选不代表已保存、资金授权或事实验证。

## 数据与维护

- 后端文件：项目根 `.zhiyin-memory.local.json`，非浏览器缓存。JSON schema version 1，最多 100 条；文件权限 0600，原子替换、独占写锁、revision 乐观并发检查；损坏时拒绝覆盖。锁文件残留会阻止保存，应停服确认无写入进程后人工处理。
- 每条记录包含 ID、文本、分类、来源摘录（最多 200 字）、来源类型、更新时间、到期时间。目标 90 天，其他 365 天，使用真实时间；过期记录仍可查看和编辑，但不提供给模型。
- 修改与删除是替换/物理删除，不保留暗中的旧版本。关闭或修改记忆会设置聊天上下文边界；历史仍可查看，但边界之前的消息不再发给模型。后台已收到的模型请求无法撤回，其迟到结果会丢弃。
- 备份应停服后复制该私有文件到受控位置；不要打进队友素材包或提交仓库。代码更新不覆盖数据。未实现自动备份、账户登录、加密、多租户隔离和云同步。
- 当前明确是**单用户、可信本机/局域网沙箱**：访问同一服务器的设备共用这份记忆，不可直接公网部署。写入要求同源和自定义 JSON 请求头，但这些不是身份认证。文件 URL 禁止静态访问。

## 上下文与检索

`useStewardMemory` 每次提问读最新状态；`memoryContext` 从未过期记录按中文相邻字符重合度排序，补充习惯/偏好，最多 5 条、约 600 字资料预算。它是有界的词面检索，不是向量语义记忆或完整用户画像。

最新用户说法优先于记忆，模型应询问冲突而非暗中改写。纠正可以在管理页修改对应条目。目前不自动合并语义相似或矛盾事实。完整对话仍只保留最近 30 条，模型最多 24 条；没有聊天档案、历史摘要或全量会话检索，持久偏好独立于该窗口。

业务状态（重复订阅选择、提醒、周期扣费确认）仍由原模块管理，不因记忆开关改变。余额、最新账单每次刷新，不从长期记忆中取。

已实现结构化 `customerContext` 服务偏好：年轻成长、家庭、财富管理、银发安全、商户／小微经营及通用客群，配合 10 类需求标签。只有用户主动选择并点击保存才写入；关闭后不发给模型。它只调整账单、理财和卡片建议的排序与解释重点，与风险测评、余额、持仓和交易权限分开。完整设计见 [微信账单一致性与客群记忆设计](wechat-bill-consistency-and-customer-memory.md)。

## 接口

- `GET /api/zhiyin/memory` → 完整状态（no-store）
- `POST` 相同地址，JSON，`X-Zhiyin-Memory: 1`，每次附 revision。
- type：`enabled`、`save`、`delete`、`clear`、`profile`、`customer-context`。save 带 id 时修改，不带时新增；同文去重。409 表示版本变化，应刷新核对，不自动重试覆盖。

接口在根 Vite 和 MobileGym Vite 的开发/预览服务器注册。新增服务器逻辑更新需要 Vite 重启；知银嵌入包需要 `npm run phone:sync`。
