# 微信群智能 AA：实现与演示说明

这是知银与 MobileGym 微信之间的浏览器沙箱联动，延续现有 `PRODUCT.md` 与 `DESIGN.md`，不改变银行 AA 流程。没有接入真实微信、好友列表或聊天记录，也没有群 AA 服务端数据库；自然语言整理使用现有模型代理。

## 演示流程

1. 启动手机沙箱，打开「知银 → 我的 → 微信群智能AA」；也可在管家对话明确提出“群收款”等需求，再点击消息中的「配置微信群AA」。
2. 点击「从微信选择群」，在沙箱微信确认共享所选群的成员标识、头像、昵称、明确填写的性别及身份备注，不共享聊天内容。仅有「周末饭搭子（演示群）」与「周末出游（演示群）」两个示例群。授权按群隔离，非好友也可参与；出游群的两位“小王”以稳定 ID 和身份备注区分。
3. 搜索昵称或身份，逐行多选参与人，或使用全选／清空。已选人数常驻显示。上方选择用于新增费用，已有费用的参与人与份数在各费用项目内调整。
4. 手动添加费用、金额、参与人和份数，或告诉宁宁如何分摊。模型可仅返回选人结果，也可返回完整费用方案；只选人不会虚构费用。支持撤销上一次方案或模型选人修改。身份不明确时应追问，模型输出的陌生成员、非法金额和无效份数会被拒绝。
5. 核对每人金额、自己承担与待收金额，点击「核对群收款 → 去微信确认发起」。微信页以「按人填金额 · 知银已填写」展示最终结果，用户再次确认才创建收款。发起不等于到账，也不会自动扣成员款。
6. 微信演示群以真实可操作的沙箱会话呈现头像、发送者昵称、时间、文字气泡与绿色群收款卡片。可以发送文字；点击右上角更多进入聊天信息，查看成员头像／昵称／性别并设置免打扰、置顶或撤销资料授权。文字消息与设置保存在浏览器中，不向真实微信群发送。
7. 点击会话内绿色群收款卡片进入该笔详情，展开「沙箱测试工具」模拟成员付款。每次首次模拟到账同时更新收款进度、微信零钱和支付账单；返回知银可自动更新或点击「刷新进度」。停止收款会阻止后续模拟付款，但不退回已到账金额。

真实微信参考图中的「均摊／按人填金额／群成员自填」并未全部做成可切换模式。目前知银负责计算，微信确认页承接已经算好的按人金额；均摊是知银费用项目的一种分配方式。

## 金额与状态约定

金额统一以整数“分”保存。每项费用按正整数权重分摊：半份权重 1，整份权重 2；逐项向下取整后按最大余数分配尾差，同余数按稳定成员 ID 排序，保证确定性与总额守恒。最多 20 个费用项目，活动总额不超过 10 万元。自己可承担费用，但不向自己收款；需至少有一位其他成员承担正金额才能发起。

模型验证案例：晚饭 600 元由我、李娜、小王均摊；酒水 180 元仅我和李娜参与，我整份、李娜半份。最终分别为 **320／260／200 元**，总额 780 元，待收 460 元。另验证“只选李娜和小王，不含我，还没确定费用”只产生成员选择，不产生费用。

“女生 a 一半”表示相对份数：其他参与人各 1 份，女生各 0.5 份，总额仍全部分完。先选我、李娜、小王，再输入“600元，女生a一半”，按当前明确资料得到 **240／120／240 元**；不能先三等分再把女生金额减半。演示资料明确设置李娜为女、我和小王为男、陈晨未填写，均不是通过姓名或头像推断。涉及性别条件且本次参与人有未知资料时，程序先确定性追问、不生成方案；未参与成员的未知资料不阻挡计算。模型仅接收明确性别等文本资料，头像在发起模型请求前移除。

知银的当前选群、未发布草稿和撤销状态仅在组件内存中，离开页面导致卸载后重置。已发布记录、授权、进度、群文字消息、免打扰／置顶设置、零钱及账单保存在该浏览器的微信沙箱存储中，刷新后仍在；不是服务端或跨设备存储。重新选择群可读取该群历史记录。断开授权不删除或退款，后续读取与发布需重新授权。

旧群状态通过 `profileVersion: 2` 迁移：清除旧授权、递增群 revision，保留收款记录与钱包；仅对已知演示成员补齐缺失资料，已有明确资料及显式 unknown 保留。新增资料必须重新确认授权，旧同意不能自动扩展为头像与性别共享。测试使用隔离状态／新浏览器，没有改写实际用户存储。

## 局部界面契约

- 知银页面沿用既有墨蓝、青绿与白色体系，最大宽度 760px。成员是一人一行的紧凑列表，含复选框、头像、昵称、身份与明确性别提示；名单区域可滚动，份数控制归属各费用项目，不混入全局选择。头像复用 MobileGym 已跟踪的本地演示素材，未新增位图资产；微信与知银展示同一成员资料。
- 主操作遵循“编辑 → 核对 → 微信确认”，处理期间禁用编辑并给出状态；金额使用等宽数字，状态同时以文字表达。按钮至少 44px 高，输入与操作保留键盘焦点样式。
- 微信页保持沙箱微信的灰底、白色内容区与原有导航手势。局部主按钮使用 `#078345` 配白字，对比度约 4.84:1；该值不扩展为知银全局主色。收款成员与金额逐行对齐，确认页区分自己承担与待收金额；进度页单独显示状态，下方三栏为「总收款／已收／未付」，不把总收款误标为剩余待收。
- 授权与群详情保留沙箱说明，模拟付款入口收于测试工具中。不得把发布、模型提案或模拟回执描述为真实微信交易。
- 会话沿用微信灰底、左白／右绿文字气泡、40px 方形圆角头像、发送者昵称和分段时间；绿色收款卡是进入详情的入口。聊天信息使用五列成员网格与带开关的设置行，开关暴露 `aria-checked`，减少动态效果时停用过渡。底部文字输入保留发送动作与移动沙箱浮层避让，不添加无功能的语音、二维码或完整微信能力承诺。

`groupAARequest` 只暴露 `choose / publish / records / revoke`，校验消息来源、同源、协议版本与请求 ID；付款模拟没有通过知银桥接暴露。发布端重新检查授权、群成员 revision 和方案，同一收款编号不能对应不同方案。首次到账使用 `group-aa:<collectionId>:<memberId>` 关联账单，重复模拟不会重复增加余额。

未来若接入具备实际权限的平台，应替换沙箱授权、群成员来源、发布及回执适配层，保留明确授权、稳定成员 ID、版本检查、逐分计算与幂等边界；真实到账应来自可验证的平台回执，不能调用模拟付款冒充。模型只产生待核对方案，不拥有发布或收款权限。模型请求目前通过 `/api/zhiyin/steward-reply`，使用既有沙箱模型配置。

## 路由与动作登记

`/group-aa` 继续作为知银 Activity 发起的外部 deepLink 授权／确认页，在普通导航图中不可达是刻意设计。`wechat.groupAA.open` 现在打开 `/group-aa/:groupId` 会话；更多通过 `wechat.groupAA.info.open` 进入 `/group-aa/:groupId/info`，收款卡通过 `wechat.groupAA.collection.open` 进入 `/group-aa/:groupId/collection/:collectionId`。

新增 `wechat.groupAA.message.submit`（发送本地文字）、`wechat.groupAA.mute.toggle` 与 `wechat.groupAA.pin.toggle`（持久设置）；`wechat.groupAA.revoke.submit` 移至聊天信息，`wechat.groupAA.payment.submit` 与 `wechat.groupAA.cancel.submit` 移至单笔收款详情。授权与发布仍使用原动作，不把会话发送动作映射成资金操作。

## 本地验证

在项目根目录安装好两端依赖后运行：

```sh
npm test
npm --prefix mobilegym test -- tests/group-aa.test.ts
npm run phone:dev
```

保持手机服务运行于 `http://localhost:3000`，另开终端执行：

```sh
node scripts/group-aa-smoke.mjs
node scripts/group-aa-model-smoke.mjs
```

浏览器 smoke 使用独立浏览器存储，覆盖资料授权、群消息发送、聊天信息、免打扰、绿色收款卡、四人平摊 600 元、双重确认、一次模拟到账 15000 分、单条账单、刷新进度及重载持久化；金额汇总断言覆盖部分收款时的「450／150／300 元」与全部收齐时的「450／450／0 元」（总收款／已收／未付）。截图输出到 `.impeccable/review/`。macOS 默认使用 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`。模型 smoke 需要现有可用模型配置，验证复杂分摊、仅选人、女生半份和参与人性别未知追问，不发布收款。

本次交付验证记录：根项目 300 项测试与构建通过；MobileGym 群／钱包／支付／财务相关 43 项测试及 TypeScript 检查通过，其中群后端 9 项通过。收尾定向 ESLint 通过，模型输入收紧为 `id/name/self/note/gender` 白名单后，14 项 AA 目标测试再次通过并完成 `phone:sync`。浏览器与模型 smoke 通过，独立最终审阅 `group_profiles_finish_review` 核对 9 张界面截图后结论为 ship；手动选择我／李娜／小王并输入女生半份也验证为 240／120／240 元。
