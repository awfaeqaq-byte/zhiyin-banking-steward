# 财务教练：图片与十个理财主题的接入设计

更新于 2026-10-09。范围是本机比赛沙箱。参考用户提供的《稳健入门指南》图片，以及 [Adam 的十个提示词主题](https://threadnavigator.com/thread/2088656838548210159/)；这里采用其问题结构，不照搬“周末解决全部财务问题”的承诺或固定输出数量。

## 图片中的四个入门问题

| 问题 | 已有能力 | 当前缺口与本轮接法 |
| --- | --- | --- |
| 我的钱要怎么用？ | 目标金额、期限、已准备金额规划；五项风险测评；理财产品比较 | 目标与风险尚未形成同一张完整财务画像。本轮让 LLM 先问目标和使用时间，再结合真实测评解释；不能把职业、年龄或聊天印象当风险等级。 |
| 钱从哪来、怎么分配？ | 已授权账单的收入和支出分类、银行沙箱余额、未来已知续费测算 | 缺少稳定薪资、固定生活费、债务、保险和其他账户。单月入账不等于可长期使用的月收入。图片的 50/20/15/10/5 和常见 50/30/20 只作讨论起点，LLM 不直接套为用户比例。 |
| 存款、货币基金、定投、股票/ETF 怎么选？ | 演示产品目录、风险适当性筛选、申购及赎回核验 | 当前没有股票/ETF 交易渠道，也没有正式实时产品数据。LLM 可以解释流动性、波动和期限差异，但只能把当前目录中的产品交给服务端筛选，不生成虚构的可购买产品。 |
| 怎样制定预算、储蓄、控风险、持续学习？ | 账单、订阅复核、目标规划、资金提醒、卡片限制 | 尚无用户确认的月度预算、自动储蓄执行、债务管理和习惯进度。先以对话探索可接受的计划，逐步收集用户选择；不能把建议说成已经设立的自动扣款或计划。 |

资产配置需要结合目标期限及风险承受能力，分散投资也不能消除所有风险；应急储备额需要结合个人支出和财务冲击。[Investor.gov 资产配置说明](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)和[美国消费者金融保护局应急基金指南](https://www.consumerfinance.gov/an-essential-guide-to-building-an-emergency-fund/)支持这一设计原则。图片中的“稳健”“收益稳定”等词是教育性描述，不作为产品保证。

## 十个主题的功能现状

| 主题 | 现状 | LLM 现在可做 | 仍需数据或执行能力 |
| --- | --- | --- | --- |
| 多元收入规划 | 未有专门模块 | 询问技能、可用时间、投入与风险，筛选少数可验证路径，分阶段讨论 | 工作、业务、市场需求和成本证据；不能默认需要七种收入 |
| 债务清偿 | 未有债务台账 | 解释高利率优先、小额优先及折中法，帮助用户选适合自己行为的方式 | 每笔本金、利率、最低还款、费用和现金流；精确利息须由计算器核验 |
| 支出漏洞 | 账单分类、异常线索、订阅复核已有 | 结合用户偏好区分必要开支、重复服务和可调整习惯 | 使用频率、家庭责任和生活质量偏好；不能凭商户名称判定“浪费” |
| 无压力预算 | 有账单及续费资金测算 | 用已授权支出作局部基线，协商弹性预算和每周复盘 | 稳定净收入、房租等未连接固定支出，以及用户确认的预算上限 |
| 薪资谈判 | 无专门功能 | 通过对话准备证据、话术及模拟异议 | 岗位、业绩、报价和可信的市场薪资来源；不可捏造行情 |
| 冲动消费控制 | 有账单与卡片开关 | 探索触发情境、等待规则和不羞辱的 30 天练习 | 用户主动标注的冲动购买样本；不能自动给交易贴心理标签 |
| 自动储蓄 | 有目标规划，银行支持有限的单次转账预约 | 规划缓冲金与逐步储蓄节奏 | 专用储蓄账户、本人账户自动转入授权与周期调度；当前不能宣称已自动储蓄 |
| 副业可行性 | 无专门功能 | 探索能力、时间、起步成本、验证实验与退出条件 | 市场、平台规则、税费及实际需求证据；不能保证首单或收益 |
| 财务仪表盘 | 银行、账单、理财、订阅页面分别存在 | 解释已知数据和缺失项，建议周/月复盘重点 | 完整负债、其他资产、保险及跨账户估值；当前不能声称完整净资产 |
| 财务思维改善 | 对话与长期记忆已有 | 给可调整的短周期行动和复盘问题 | 用户授权的习惯目标与进度；避免空泛激励或默认 21 天固定模板 |

## 本轮实现：一个可扩展的对话提示词

1. [财务教练提示词](../src/prompts/financial-coach.v1.md)可单独迭代；[上下文组装](../src/lib/financial-coach.ts)只做轻量意图路由和数据边界处理。十个主题的具体路径由 LLM 根据用户当前问题选择，不建十套固定问卷或流程。
2. 对话读取当前银行沙箱余额、已授权账单月度摘要、已知续费与风险测评。每项注明范围；未授权、数据不完整或未提供的债务和薪资都标为未知。
3. 提示词要求先确定目标、期限、现金流和风险，再讨论储蓄或投资；只追问一个最关键的问题，保留 2–3 个简短选项。用户明确要求长计划时才展开阶段任务。
4. LLM 负责解释、权衡、提问和草拟行动；金额统计、适当性、余额、限额、资金扣划与用户确认仍由已有服务端流程负责。任何具体申购、赎回或转账都不得通过聊天回答直接执行。
5. 现有账单、卡片、转账和订阅操作仍走原有核验链路；财务教练是一种对话入口，不改变这些服务端接口。

## 下一轮数据与体验优先级

先做可由用户逐项确认的财务档案：稳定净收入区间、必要固定支出、债务清单、应急金目标、短中长期目标及计划复盘频率。每项保存来源、更新时间和是否由用户确认。由此再支持可编辑预算与债务策略对比；精确的还款、储蓄及目标预测接确定性计算器。最后再考虑经独立授权的周期储蓄执行与进度提醒。

用真实场景评估提示词，而不只检查关键词：资料齐全、资料缺失、收入波动、债务利率高于预期收益、消费分类错误、用户反对削减某项支出、低风险测评却索取高波动产品、同一句同时谈预算和理财。评价是否有来源、是否问对一个关键问题、是否尊重用户取舍，以及是否错误声称已经操作。
