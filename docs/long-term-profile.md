# 长期印象（用户画像）

入口：个人中心 → 管理记忆 → 我对你的理解。先开启长期记忆，再开启独立的“从对话积累长期印象”。不修改已有用户开关，也不导入演示偏好。

## 数据与更新

- 与长期记忆共用后端文件及版本锁；旧版文件无 `profile` 时自动按未开启处理，无破坏性迁移。
- 第一版覆盖沟通、音乐、交通、餐饮、购物五个主题，每个主题保留一条当前综合理解与最近原话依据，避免无限堆积标签。
- 模型可在回复中提出 `<impression>` JSON；客户端和后端验证主题、长度及原话引用。有效观察在开启后自动存为暂定理解。普通 `memory` 候选仍需逐条确认，同一回复有明确记忆候选时不再保存画像。
- 暂定理解 90 天后不再注入；用户确认或纠正的理解 365 天后需核对。不是连续置信度衰减，也不把重复模型输出算作多次独立证据。
- 确认印象不允许被模型覆盖，冲突时提示模型询问用户，并在管理页纠正。最新用户话语优先，但语义遵循仍依赖模型。
- 忘记会删除内容及引用，只保留“不再自动积累此主题”的设置；可以恢复，从新对话开始。清空全部记忆也清空画像并停止主题积累。
- 修改、忘记、开关操作会隔离旧模型上下文；自动积累不会切断正常对话。历史聊天不删除。

## 边界

画像影响建议和表达，不是账户事实或交易授权。重要资金偏好走明确记忆确认；不推断风险承受能力、收入、健康或敏感身份。

目前只基于用户对话，不自动扫描历史账单生成画像，不是向量检索或人格评测。领域白名单、敏感词与原话匹配只能做有限校验，不能证明模型概括语义正确，因此所有自动理解均明确标为暂定，供用户纠正。

本地单用户沙箱，没有账号隔离。开关开启后画像会随提示词发给已配置模型服务。实际模型输出稳定性未做线上评测；自动测试用受控模型回复验证持久化、纠正、关闭、遗忘、预算和上下文接入。
